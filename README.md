## 📌 Sobre o Projeto

Projeto realizado como parte do curso de QA, com foco em **testes de regressão** no Urban Routes — um aplicativo de rotas que calcula tempo e custo de viagens para diferentes meios de transporte.

---

## 🎯 Objetivo do Projeto

- Executar casos de teste funcionais e de regressão no Urban Routes  
- Verificar se as funcionalidades continuam estáveis após alterações  
- Identificar e registrar bugs detalhados para apoiar o time de desenvolvimento

---

## 🔧 Tecnologias e Ferramentas Utilizadas

- Testes manuais
- Navegador Google Chrome
- Google Sheets (gestão de testes e bugs)

---

## ▶️ Como Executar

1. Iniciar o servidor do Urban Routes e abrir o app no Google Chrome.  
2. Consultar o **modelo de casos de teste** no Google Sheets.  
3. Executar cada caso de teste, comparando o resultado real com o esperado.  
4. Marcar o status: ✅ Aprovado | ❌ Reprovado | 🔸 Ignorado.  
5. Se encontrar bugs, registrar um **relatório de bug** detalhado na aba apropriada da planilha.  
6. Informar o **ID do bug** correspondente para rastrear a falha. 

---

## 🧾 Resultado

- Todos os casos de teste do modelo foram executados.  
- Foram identificados bugs que impactam a experiência do usuário.  
- Relatórios de bug foram documentados com informações completas: ID, título, etapas, resultado esperado, resultado real e prioridade.  

---

## 📚 Aprendizados

- Reforço na execução de testes regressivos e validação funcional.  
- Prática em reportar falhas de forma clara e rastreável.  
- Entendimento do impacto de bugs não resolvidos na experiência do usuário.

## 🇺🇸 Project Summary

This project was part of a QA course focused on **manual regression testing** for the Urban Routes app — an application that calculates route time and costs for different transport modes. The goal was to execute functional and regression tests, verify if the features work correctly after changes, and report bugs clearly using Google Sheets.
