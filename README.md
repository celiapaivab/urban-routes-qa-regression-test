## 📌 Project Overview

This project was developed as part of a QA course, focusing on **regression testing** for Urban Routes — a route planning application that calculates travel time and cost across different modes of transportation.

---

## 🎯 Project Goals

- Execute functional and regression test cases in Urban Routes  
- Verify whether existing features remain stable after updates  
- Identify and log detailed bugs to support the development team

---

## 🔧 Technologies and Tools

- Manual testing  
- Google Chrome browser  
- Google Sheets (test management and bug tracking)

---

## ▶️ How to Run

1. Start the Urban Routes server and open the app in Google Chrome  
2. Refer to the **test case template** in Google Sheets  
3. Execute each test case, comparing actual vs expected results  
4. Mark status as: ✅ Passed | ❌ Failed | 🔸 Skipped  
5. If bugs are found, log a **detailed bug report** in the appropriate sheet tab  
6. Record the corresponding **Bug ID** for tracking

---

## 🧾 Results

- All test cases from the template were executed  
- Bugs affecting user experience were identified  
- Bug reports included complete information: ID, title, steps, expected result, actual result, and priority
